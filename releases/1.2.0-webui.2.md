# test Web UI

Experimental Windows x64 prerelease from `feature/local-web-ui`.

## Updated in 1.2.0-webui.2

Death markers now show the player's nickname directly on the map beside the timestamp.

## Changes

- Local web panel for connection settings, server players, tracked players, devices, alarms and death-watch.
- Settings persist to JSON and apply to the running bot; connection changes reconnect it.
- Pairing notification inbox with explicit server/device application and BattleMetrics server lookup.
- Rust+ map with zoom, pan, game grid, team positions and saved death markers labelled with player name, date and time.
- Team chat history polling supplements broadcasts, deduplicates commands and reports unconfirmed outgoing messages.
- Separate `Start-WebUI.cmd` and `Stop-WebUI.cmd` launchers.

## Running

Extract into a new folder. Run `Start-WebUI.cmd`, then open http://127.0.0.1:8787.
Configure the server and your Rust+ registration file in Settings. Start the bot from the panel.
Use `Stop-WebUI.cmd` to stop both the bot and the panel. Closing the browser leaves the panel running.

Existing users can copy their private `conf` and `sounds` into this new folder after backing them up.
Do not overwrite your private configuration with the bundled examples.

The executable does not require Go. The optional pairing notification listener requires Node.js,
`@liamcottle/push-receiver@0.0.3` and an existing Steam/FCM registration; see WEBUI.md.
Vending machine markers are unavailable in the current standard Rust+ API.

The archive contains example configs only. Personal credentials, logs and sound files are excluded.
This is a prerelease; stable release 1.1 remains available separately.
