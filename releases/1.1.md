# RustPlusBot 1.1

Windows x64 release, built with Go 1.27.4.

## Changes

- Authenticated Rust+ companion socket replaces the old IP/port/proxy configuration.
- Startup verifies a server reply and stops after at most 60 seconds of failed attempts.
- Established sessions reconnect automatically after connection loss.
- Startup errors are logged and wait for Enter in an interactive console.
- Updated Protobuf schema and generated bindings, including 64-bit device IDs.
- Connection, timeout, reconnect and schema regression tests.
- `--check-connection` verifies credentials without device actions or chat messages.
- `--version` prints the release version.

## Upgrading from 1.0.0

Back up your old folder. Extract 1.1 into a new folder so the example configs do not overwrite your private configuration.

Update `conf/rpconfig.json` with `server_id`, `player_id` and `player_token` from a server pairing notification. Set `auth_token_file` to your saved Rust+ registration file containing `rustplus_auth_token`. See CONNECTION.md. Old `server`, `port` and `use_proxy` fields no longer configure the bot.

Copy your BattleMetrics config, bot config and sound files from your backup. Device bindings are specific to a Rust server; rebind them when switching servers. Keep your registration file and tokens private.

Run `main.exe --check-connection` first, then launch `Start-RustBot.cmd` or `main.exe` normally.

The archive contains example credentials and an empty bot configuration. Personal credentials, logs and sound files are not included.
